# Amanda Amaral Estética e Beleza - Site Estático

Este é o arquivo estático do site pronto para hospedagem.

## Como publicar

1. Faça upload de todos os arquivos desta pasta para o seu servidor de hospedagem.
2. Certifique-se de que o arquivo `index.html` esteja na raiz.
3. O arquivo `assets/hero-video.mp4` é o vídeo de fundo do hero.
4. Substitua as imagens em `assets/` pelas fotos reais quando disponíveis.

## Conteúdo

- `index.html` - Página principal
- `assets/` - Imagens, vídeo, CSS e JavaScript
- `favicon.ico` - Ícone do site
